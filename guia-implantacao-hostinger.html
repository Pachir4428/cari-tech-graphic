Guia de Implantação

Como publicar seu site na Hostinger

Cari Tech Graphic — passo a passo completo, do upload ao site no ar.

Antes de começar

Você vai precisar de:

  • Conta ativa na Hostinger com um plano de hospedagem
  • O arquivo ZIP do projeto baixado (Cari Tech Graphic)
  • Um domínio configurado (ou usar o subdomínio gratuito da Hostinger)

Passo a passo

1

Baixe e descompacte o ZIP

Localize o arquivo ZIP do projeto no seu computador e descompacte-o em uma pasta de fácil acesso. Você verá os arquivos .html, .css, .jsx e .js que compõem o site.

2

Acesse o hPanel da Hostinger

Entre em hpanel.hostinger.com com sua conta e selecione o site/domínio onde quer publicar.

3

Abra o Gerenciador de Arquivos

No menu lateral, clique em Arquivos → Gerenciador de Arquivos. Depois, entre na pasta public_html — é a pasta raiz do seu site.

4

Limpe arquivos padrão

Se houver arquivos pré-existentes como default.php, index.html em branco ou pastas vazias da Hostinger, selecione e exclua para não causar conflito.

5

Faça o upload dos arquivos

Clique no botão Upload (ícone de seta para cima, no topo do gerenciador). Selecione todos os arquivos descompactados — os arquivos soltos, não a pasta. Aguarde o upload finalizar.

Dica Para acelerar, recompacte tudo em um novo ZIP, envie esse ZIP e use a opção "Extract" do Gerenciador de Arquivos para descompactar direto no servidor.
6

Renomeie o arquivo principal

Para que o site abra automaticamente no domínio, o arquivo Cari Tech Graphic.html precisa virar index.html.

Clique com o botão direito sobre ele → Renomear → digite index.html → confirme.

Importante Sem esse passo, o navegador vai exibir uma lista de arquivos em vez do site, ou um erro 403/404.
7

Teste o site

Abra seu domínio no navegador. Se aparecer cache antigo ou tela em branco, force um hard refresh: Ctrl + Shift + R (Windows) ou Cmd + Shift + R (Mac).

Estrutura final esperada

Dentro de public_html/ você deve ter:

public_html/
├── index.html          ← renomeado de "Cari Tech Graphic.html"
├── sobre.html
├── admin.html
├── app.jsx
├── i18n.js
├── icons.jsx
├── sections-1.jsx ... sections-5.jsx
├── styles.css
├── styles-extras.css
├── styles-modals.css
├── styles-sections.css
├── styles-sections-2.css
├── dotted-surface.js
├── tweaks-panel.jsx
└── uploads/

Configurações recomendadas

Ativar HTTPS (SSL)

No hPanel, vá em Segurança → SSL e ative o certificado gratuito Let's Encrypt. É 1 clique e deixa seu site com cadeado verde.

Domínio personalizado

Em Domínios → Gerenciar, configure os DNS para apontar para a Hostinger. Pode levar até 24h para propagar.

Cache e performance

Ative o LiteSpeed Cache no hPanel para o site carregar mais rápido para visitantes recorrentes.

Backup automático

Habilite os backups diários em Arquivos → Backups para conseguir restaurar o site caso algo dê errado.

Resolução de problemas

  • Tela em branco: verifique se o index.html foi renomeado corretamente e está em public_html/.
  • Imagens não aparecem: confirme que a pasta uploads/ foi enviada por completo, com permissões 755.
  • CSS quebrado: verifique se todos os arquivos .css estão no mesmo nível que o index.html.
  • Erro 403: selecione todos os arquivos no gerenciador → botão direito → Permissões → defina 644 para arquivos e 755 para pastas.
  • Site não atualiza: limpe o cache do navegador e do LiteSpeed (em Avançado → Gerenciar cache).
